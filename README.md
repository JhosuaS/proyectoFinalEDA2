# Proyecto de fin de curso para EDA II
* **Miembros:**
  * `JhosuaS`: Jhosua Saa

El proyecto consiste en el uso de algoritmos de *pattern matching* como KMP y Booyer-More para la detección de patrones en textos y mensajes de estudiantes universitarios que permitan la detección de factores de riesgo en su estudio y sirva como guía de diagnóstico para profesionales y tutores.
